# Skyward Astronaut

เกม 3D Platformer สองด่านสำหรับ Godot 4.7.2 ตามแบบฝึกหัดที่ 5 ผู้เล่นควบคุม Astronaut กระโดดข้ามช่องว่าง หลบกับดัก เก็บดาวด่านละ 6 ดวง แล้วเข้าประตูเพื่อไปต่อ ด่านที่ 1 คือสถานีวงโคจร และด่านที่ 2 คือฐานดวงจันทร์ ทั้งสองด่านใช้โมเดลจาก Space Habitat Kit ของ Poly Pizza พื้นแต่ละเกาะมีแผงทางเดิน ไฟนำทาง เสาอากาศ และแผงพลังงาน ตัวละครปรับให้เล็กลง 40% และหน้าจอเกมเป็นธีมอวกาศ

## วิธีเล่น

เปิด `project.godot` ด้วย Godot 4.7.2 แล้วกด F6 หรือ F5 เพื่อเล่น ใช้ WASD หรือปุ่มลูกศรเพื่อเคลื่อนที่ กด Space หรือ Enter เพื่อกระโดด และกดซ้ำกลางอากาศเพื่อกระโดดสองจังหวะ กด R เพื่อเริ่มใหม่เมื่อพลาด ดาวที่เก็บแล้วจะยังอยู่หลังเกิดใหม่ เมื่อจบทั้งสองด่านกดปุ่ม `PLAY AGAIN` หรือ R เพื่อเริ่มเกมใหม่

## โครงงาน

- `scenes/game.tscn` คือฉากหลัก
- `scripts/game.gd` สร้างสองด่าน ระบบดาว กับดัก ประตู ฉากสถานีอวกาศ และหน้าจอเกมพร้อมปุ่มเริ่มใหม่
- `scripts/player.gd` ควบคุมตัวละครและเลือกแอนิเมชัน Idle, Run, Jump พร้อมหมุนตัวในจังหวะกระโดดสองครั้ง
- `assets/astronaut.glb` คือตัวละคร Astronaut จาก Poly Pizza
- `assets/habitat/` รวมโมเดลดาวเคราะห์ ดวงจันทร์ โมดูลพักอาศัย ยานสำรวจ รถสำรวจ และสถานีอวกาศ
- `starter_reference/` เก็บสคริปต์ผู้เล่นต้นฉบับและใบอนุญาตของ Starter Kit เพื่อให้เห็นส่วนที่นำมาปรับใช้
